Este repositorio contiene mi portafolio profesional de **Inteligencia de Fuentes Abiertas (OSINT)** y **Ciberseguridad**. Aquí documento investigaciones técnicas, metodologías de geolocalización y análisis de activos digitales.

## 🚀 Propósito
El objetivo de este espacio es demostrar mis habilidades técnicas en:
- **Investigación Digital**: Aplicación de metodologías estructuradas para la obtención de inteligencia.
- **IMINT & Geolocalización**: Verificación de imágenes y localización geográfica mediante análisis visual avanzado.
- **Writeups Técnicos**: Documentación detallada de retos resueltos en plataformas como TryHackMe, HackTheBox y Gralhix.

## 🛠️ Tecnologías Utilizadas
- **Jekyll**: Generador de sitios estáticos para el despliegue en GitHub Pages.
- **Custom CSS/JS**: Interfaz profesional con efectos de terminal y diseño responsivo.
- **OSINT Tools**: Maltego, Shodan, SpiderFoot, Recon-ng, entre otras.

## 📁 Estructura del Proyecto
- `_posts/`: Colección de writeups e investigaciones.
- `assets/`: Recursos visuales y documentos (CV, imágenes).
- `herramientas.md`: Mi arsenal personal de herramientas recomendadas.
- `retos.md`: Índice estructurado de retos por plataforma.
